# Dichang Zhang — personal website

Built with [Academic Pages](https://github.com/academicpages/academicpages.github.io) (MIT license).

- `_pages/about.md`: biography and selected/other publications.
- `_pages/cv.md`: public CV, adapted from a separate visa CV.
- `_data/publications.json`: publication metadata and existing paper/code links.
- `files/Dichang_Zhang_CV.tex` and `.pdf`: downloadable public CV.
- `_config.yml`: profile and site settings.

Run `bundle install` then `bundle exec jekyll serve` to preview.
GitHub Pages builds the `main` branch with Jekyll.
